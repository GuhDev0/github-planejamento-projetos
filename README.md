<h1 align="center">Planejamento de Projetos com GitHub</h1>

###

<h4 align="left">Muita gente conhece o Git, mas não usa o GitHub como ferramenta de organização — e isso pode estar te atrapalhando sem você perceber.<br><br>Quantas vezes você já tentou começar um projeto e se sentiu completamente perdido?<br><br>Isso acontece com frequência, e na maioria das vezes é por falta de planejamento. Mas a boa notícia é: o GitHub tem recursos que podem te ajudar a mudar isso completamente!</h4>

###

<p align="left">💡 Ideal para quem está começando e quer aprender a planejar projetos com mais clareza e produtividade.</p>

###

<h2 align="left">✅ O que você vai aprender</h2>

###

<h4 align="left">Criar e usar Issues para dividir tarefas<br><br>Organizar o fluxo do projeto com Projects (Kanban)<br><br>Como dar sentido aos Commits, ligando-os a tarefas reais<br><br>Por que pequenos passos são melhores do que tentar fazer tudo de uma vez</h4>

###

<h2 align="left">- Usando Issues para dividir tarefas</h2>

###

<h4 align="left">As Issues servem para você listar tudo o que precisa fazer no seu projeto, separando por partes pequenas. Assim, você consegue desenvolver um passo por vez, sem se perder no todo.</h4>

###

<p align="left">“É melhor dar pequenos passos do que tentar fazer tudo de uma vez e acabar desistindo.”</p>
